🎀Description🎀

 The GKS-U 2027 eligibility checker is a program in Python that checks the basic eligibility requirements for the 2027 Global Korea Scholarship.

 The program asks the user for their age, high school average percentage and nationality, then displays whether each requirement is satisfied or not.

💡Why I made this💡

 I created this eligibility checker as my final project for CS50's Introduction to programming with python (CS50P).

 I thought of making this project as it's relevant to my own goals of GKS-U. When i first discovered GKS scholarship, i was struggling to understand if I pass the basic criteria and also confused about what track i can apply through. I have seen many people being confused about the same thing when they get to know about this scholarship for the very first time, so i thought of making this program which helps them solve that confusion.

🌟Features🌟

-🎂 checks age eligibility
-📊 checks grades eligibility
-🌍 gives nationality-based track choices
-🩺 handles invalid numeric input
-📂 uses functions to organize the eligibility checks
-🧪 includes automated tests

⚙️How it works⚙️

The program takes three inputs:
1) 🎂 age
2) 📊 high school average percentage
3) 🌍 country of nationality

It then checks each input by the user against the set criteria based on the GKS-U 2027 Guidelines and displays the check result.


▶️How to Run▶️

⚠️ Limitations

This program is a learning project and should not be considered an official GKS eligibility determination.

GKS requirements may change between application years, so applicants should always refer to the latest official GKS-U guidelines and university-specific information.
